## Подтверждённые расхождения и исправления

Причина: функция `segmented()` трактует `at` как начало проёма.
Старые жёстко заданные значения в нескольких стенах использовали
значения, похожие на центры или не учитывали половину ширины.

| Проём | Было в презентации | Источник редактора | Итог |
|---|---|---|---|
| Зал (дверь) | центр z=2,70 | z=2,00 | Из общего JSON |
| Кухня (дверь) | центр z=2,00 | z=1,30 | Из общего JSON |
| Гардеробная (дверь) | центр z=-1,80 | z=-2,36 | Из общего JSON |
| Спальня (дверь) | центр z=-1,595 | z=-2,07 | Из общего JSON |
| Ванная (дверь) | центр x=7,80 | x=7,30 | Из общего JSON |
| Левый проход | центр z=-1,805, ширина 1,13 | z=-2,07, ширина 0,95 | Проход без двери и коробки; высота 2,99 |
| Окно лестницы | центр x=11,555 | x=11,35 | Из общего JSON |
| Окно спальни слева | центр z=-3,225 | z=-3,20 | Из общего JSON |
| Фасадные окна и вход | расхождения до 0,025 | координаты редактора | Из общего JSON |

Все указанные координаты и размеры относятся к **концептуальному плану в метрах**.
Физические измерения здания по-прежнему отсутствуют.

Дополнительно: к лестнице добавлена узкая кромка перекрытия в точке выхода на
второй этаж, соответствующая существующему `buildUpperFloor()` редактора.
Полное перекрытие не вставлялось в открытую презентацию:
это перекрыло бы сверху весь обзор интерьера.

## Сохранено без изменений
- Утверждённый JSON редактора, лестничный профиль и количество ступеней.
- Остальная мебель, освещение, материалы, внешний двор и камеры презентации.
- Существующий задний *дополнительный* оконный декор (2 окна) оставлен:
  редактор этих проёмов не содержит, но их удаление без фото/обмеров
  было бы риском разрушения ранее согласованного фасада.

## Нерешённые вопросы
- Некоторые стены интерьера в старой презентации по-прежнему имеют
  собственные начальные/конечные координаты (в пределах десятков сантиметров).
  Этот этап выравнивает **проёмы**, а не перестраивает полностью все стены.
- Задние 2 дополнительных окна пока не сопоставлены с редактором.
- Шесть верхних подъёмов лестницы в модели имеют неодинаковую высоту
  по отношению к нижним: строительство по такому чертежу недопустимо.
- Плита второго этажа в обзорной презентации показана только у лестничного
  выхода. Полная плита доступна в синхронной модели; в презентации она бы
  скрыла помещения при виде сверху.
- Сравнение с реальными фотографиями требует качественных фото под одинаковыми
  ракурсами и размеров на месте.
