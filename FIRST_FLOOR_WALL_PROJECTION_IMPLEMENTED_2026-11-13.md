# ADKH House · Реализация исправленной геометрии стен

Дата: 2026-11-13  
Ветка: `feature/first-floor-wall-projection-2026-11-13`  
Статус: **новый опциональный код построения геометрии готов; в пользовательской презентации ещё не включён**.

## Что сделано

1. В `shared/first-floor-wall-projection.mjs` реализован консервативный алгоритм `consolidatedPinnedWallProjection(model,segments)`. Он работает только с согласованной парой `livingBack` / `bedFront`; остальные стены не трогает.
2. Два частично наложенных параллельных объёма заменяются двумя неперекрывающимися участками с точно тем же наружным контуром. Площадь лишнего наложения: **2,053 м²**.
3. Из двух исходных поверхностей сохраняются разные цвета: со стороны зала `#e9e2d8`, со стороны спальни `#e9e4db`.
4. `architectureGeometry(project,{consolidateOverlappingWalls:true})` позволяет получить исправленный набор `segments` **по явному запросу**. Старое поведение `architectureGeometry(project)` не изменено.
5. Включены защитные отказы: если появились проёмы в стенах-кандидатах, стеновые элементы уже разбиты, отсутствует цвет одной из поверхностей или стены больше не пересекаются — коррекция отменяется и выдаётся причина.
6. Добавлен `tests/first-floor-wall-projection.mjs` с проверкой сохранности проёмов, мебели, лестницы, комнат, исходного JSON и защитных отказов. Новый тест включён в GitHub Actions.

## Почему не переключили основную презентацию

На компьютере есть более новая, пока не синхронизированная ветка `feature/warm-premium-materials-lighting`. Изменение старого `index.html` в GitHub прямо сейчас рискованно: может конфликтовать с современными материалами, камерами и редактором. Новый геометрический режим подготовлен отдельно для безопасной интеграции после синхронизации.

## Лестница — отдельная нерешённая задача

При ровном подъёме ~155,8 мм до верхнего перекрытия остаются четыре конструктивных подъёма. Удалять их или переназначать высоты остальных ступеней нельзя. Понадобится точно определить площадку и границы перекрытия; текущий расчёт `upperStairContinuityPreview` диагностирует этот дефект, но **не выдаёт согласованную строительную геометрию**.

## Следующий безопасный порядок

1. Перенести локальную ветку Warm Premium на GitHub отдельной веткой.
2. Выполнить `node tests/first-floor-wall-projection.mjs` и остальные геометрические тесты, а также посмотреть на GitHub Actions.
3. Включить новый режим стен в отдельной экспериментальной версии презентации и проверить рендер с обеих сторон стены.
4. После сверки выхода лестницы на второй этаж отдельно исправить её визуализацию и протестировать проход.
5. Только после подтверждения объединять с `main`.
