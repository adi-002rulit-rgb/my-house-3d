# ADKH House — безопасные горячие клавиши редактора

Изменён только `editor.html`. Настроена работа клавиатуры на компьютере:

| Клавиша | Действие |
| --- | --- |
| R | Повернуть выбранную мебель на 90° |
| Ctrl/Cmd+D | Дублировать выбранную мебель через существующую команду |
| Delete / Backspace | Удалить выбранный объект; для архитектурных объектов требуется подтверждение |
| Ctrl/Cmd+Z | Отменить |
| Ctrl/Cmd+Shift+Z / Ctrl+Y | Повторить |
| Ctrl/Cmd+S | Сохранить |
| Escape | Снять выделение |
| Стрелки | Перемещение камеры; Shift+стрелки — сдвиг плана |

Сетка уже есть в редакторе: 5, 10 и 25 см либо без привязки. Значение по умолчанию 10 см оставлено, чтобы не менять согласованное поведение.

## Ограничения
- Угол поворота мебели внутри редактора хранится в **радианах**, не в градусах.
- Не устанавливаем второй слушатель клавиатуры и не создаём `window.shortcutManager`.
- Все действия проходят через штатные функции `validate`, `push`, `refreshAll`, `duplicateSelected`, `removeSelected` и существующую историю.
- Горячие клавиши не срабатывают при вводе текста и в редактируемых элементах.
- Визуальные браузерные тесты на desktop и iPhone ещё не выполнялись. Держать отдельную ветку до проверки.

## Ручная проверка
1. Выделить диван → R → угол меняется на 90° → Ctrl+Z отменяет → Ctrl+Shift+Z возвращает.
2. Выделить диван → Ctrl+D → создаётся копия → Undo возвращает исходное состояние.
3. Выделить дверь → Delete → запрос подтверждения, при отмене дверь остаётся.
4. Печатать R и Backspace в текстовом поле → модель не меняется.
5. Проверить смену шага сетки 5/10/25 см и редактирование на iPhone без аппаратной клавиатуры.
