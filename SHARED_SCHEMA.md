# ADKH House: единый контракт данных (этап 2A)

## Резервная копия
Исходная точка: `main` коммит `11921ed07c829549c2b4c40bcce9bc8f82d0c720`.
Ветка-архив: `backup/pre-shared-schema-2026-11-11`.
Рабочая ветка: `feature/shared-schema-foundation-2026-11-11`.

## Контракт
Единый чистый ESM-модуль: `shared/project-contract.mjs`.
Общий JSON: `{ "format": "adkh-house-project", "formatVersion": 1, "model": { ... } }`.
`model` — точный снимок существующей модели редактора формата `version: 1`:
`title, height, elevation, walls, openings, rooms, furniture, stairs`.
Координаты, высоты и материалы **не конвертируются**. Никакого изменения размеров ради совпадения сцен.

## Что реализовано
1. Редактор проверяет общий контракт и сохраняет дополнительный снимок в
   `localStorage['adkh-house-shared-project-v1']` после обычного сохранения.
2. Кнопка `⇄ Общий JSON` скачивает переносимый JSON-конверт.
3. Презентация `⇄ Данные проекта` читает общий снимок на том же origin и
   показывает истинные числовые данные и список комнат, не перерисовывая 3D.
4. `↑ Общий JSON` в презентации позволяет проверить файл с другого устройства.
   Эта операция **не пишет** в сохранения редактора.
5. Общий модуль используется обеими страницами и проверяется тестами.

## Открытые ограничения и следующий этап 2B
- Презентация по-прежнему имеет **независимую сцену** (ручные координаты),
  поэтому числовое описание из редактора пока не управляет её геометрией.
- Для настоящей синхронизации необходимо сопоставить все стены, проёмы, комнаты,
  лестницы, покрытия, координатные оси и настройки этажей. До подтверждения
  точности нельзя заменять презентационные меши автоматически.
- Не сохранять в репозиторий частные локальные правки без экспорта JSON.
- Проверить реальный Safari на iPhone и сценарии с отключённым localStorage.
- Подтверждать конкретные визуальные результаты сравнением снимков,
  а не одним только успешным тестом.

## Обратная совместимость
Обычные `↓ JSON` и `↑ Загрузить` редактора используют старый формат `version: 1`.
Общий конверт — **новый параллельный формат**. Он не заменяет пользовательский файл.
Если общий ключ localStorage заполнен старой версией, презентация показывает
ошибку формата, а не исправляет модель сама.
