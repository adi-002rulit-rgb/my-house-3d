## Реализовано
- Синхронный режим показывает мебель из JSON редактора: диван, журнальный
  столик, кровать, кухонный шкаф и обеденный стол; расположение, поворот,
  размеры и базовый цвет берутся из редактора, не из старой презентации.
- Стены теперь используют цвета отделки **с обеих сторон** по правилам
  определения помещений в исходном редакторе.
- Цвета полов переносятся из данных каждой комнаты без подстановки
  интерьерных пресетов старой презентации.
- Статические тесты сравнивают ID, размеры, цвет и позицию каждого
  исходного предмета и цвета отделки с результатом построения.
- Браузерные тесты сохраняют отдельные скриншоты desktop/mobile
  синхронизированной модели для последующего визуального сравнения.

## Неизменные свойства
- Ни один размер стены, окна, проёма, перекрытия или лестницы в JSON
  не изменён; подготовленные ранее согласованные значения сохранены.
- Старый интерьерный просмотр с декоративными материалами доступен
  отдельно и не перезаписывается.
- Изменения работают только для синхронного режима.
- Снимки локального состояния и файл JSON не переписываются презентацией.

## Ограничения
- В синхронном режиме пока только редакторская базовая мебель, а не
  вся авторская мебель и декор старой презентации.
- Для строгого *визуального* совпадения нужно проверить сохранённые
  кадры вручную по одинаковым камерам и фактическим фотографиям;
  успешный тест числовых параметров не подтверждает фотографическую
  точность модели.
- Требуются реальные замеры лестницы и проверка на iPhone Safari.
- Особые проёмы, фактуры поверхности, дверные коробки и несущие
  элементы лестницы пока упрощены.
