# ADKH House · отдельный 3D-инспектор геометрии

**Дата:** 2026-11-13  
**Ветка:** `feature/stair-continuity-preview-2026-11-13`

## Результат

Добавлен `first-floor-geometry-preview.html` — экспериментальный просмотр первого этажа на Three.js.

В интерфейсе предусмотрены:
- переключение **До исправления / После исправления**;
- камеры **Сверху / Сбоку / 3D ракурс**;
- цветовая маркировка новой перегородки, верхних ступеней и плит перекрытия;
- цифры по шагу лестницы, наложению стен и новому проёму;
- мобильная адаптация, OrbitControls и экран ошибки, если WebGL не загрузился.

Новый инспектор читает только `APPROVED_HOUSE_V1`, `architectureGeometry` и `experimentalFirstFloorGeometry`. Никаких сохранений в локальное хранилище, изменения редактора или `main` нет.

## Проверено

- Файл создан и повторно прочитан из GitHub.
- Расчётная геометрия первого этажа ранее была исполнена в JavaScript: 10 верхних ступеней, подъём ~155,83 мм, расширение проёма ~1,054 м, исключение объёма наложения стен 2,053 м².
- Добавлен `tests/first-floor-geometry-preview.mjs` для проверки необходимых элементов HTML, связей с модульными файлами и отсутствия постоянной записи; включён в GitHub Actions.

## Не проверено

- Полноценный WebGL-рендер и взаимодействие на физическом iPhone.
- Фактическое выполнение всех тестов GitHub Actions: статус не подтверждён.
- Столкновения ступеней с дверью кладовой, достаточная высота прохода, геометрия лестничной площадки на стройке.
- Соответствие последней локальной версии Warm Premium: компьютер офлайн, изменения на GitHub не синхронизированы.

## Запуск после появления компьютера

Рабочий проект **не переключать** на старую GitHub-ветку. Вместо этого создать отдельный git worktree:

```powershell
cd D:\ADKH-DEV\05_ADKH-House
git fetch origin
git worktree add D:\ADKH-DEV\House-Audit-Preview origin/feature/stair-continuity-preview-2026-11-13
cd D:\ADKH-DEV\House-Audit-Preview
python -m http.server 8765
```

В браузере открыть: `http://localhost:8765/first-floor-geometry-preview.html`.

Обязательное условие: интернет для загрузки Three.js по CDN, WebGL в браузере, локальный Python. Если каталог `D:\ADKH-DEV\House-Audit-Preview` уже существует, выбрать новый пустой путь; **не удалять** существующие файлы.
