# ADKH House 2B — синхронизированная архитектурная геометрия

Контрольная точка: `d3446f67cc4fd71f461c9bbd1955c69e20662d72`.
Backup-ветка: `backup/pre-geometry-sync-2026-11-11`.
Рабочая ветка: `feature/geometry-sync-2b-2026-11-11`.

## Два режима без разрушительных миграций

- **Интерьерная презентация** остаётся полностью доступной и не переписывается.
  Её отдельные ранее существовавшие координаты и дизайн по-прежнему независимы.
- **Синхронная 3D-архитектура** строится динамически из экспортированного
  JSON редактора. Это отдельная Three.js-группа, которую можно включить
  кнопкой в панели «⇄ Данные проекта», и отключить без сохранения изменений.
- В синхронном режиме старый дом и крыша скрыты, поэтому не возникает
  наложения двух наборов несогласованных стен.
- При обновлении общего JSON из соседней вкладки синхронная 3D-группа
  пересобирается. При ошибке в данных прежняя группа не должна исчезать.
- На другом телефоне/компьютере нужно импортировать **общий JSON** —
  localStorage между устройствами не синхронизируется.

## Источник размеров и охват

`shared/architecture-geometry.mjs` читает только данные
`shared/project-contract.mjs`, не изменяет их и строит числовые
примитивы в метрах. Система переносит:
- стены с вырезами на заданных отметках дверей/окон/проходов;
- стекло/рамки окон и полотна дверей, с идентификаторами оригинальных проёмов;
- прямоугольники пола семи комнат;
- три марша лестницы и два забежных поворота, с шестью видимыми ступенями
  третьего марша по существующей концепции;
- плиты верхнего этажа с вырезом по габаритам лестницы.

Это **точное использование координат и числовых габаритов редактора**,
но пока упрощённая геометрическая визуализация:
- лестничные несущие косоуры/сложное бетонное подшивание из редактора
  не повторяются; ступени отображены плоскими 3D-профилями;
- мебель и премиальные декоративные материалы остаются в отдельном
  интерьерном режиме, пока не будет общей модели материалов/предметов;
- навигация и коллизии прежнего тура не основаны на новой геометрии.
  Для проверки новой геометрии используйте обзорную камеру/OrbitControls;
- перемещение/поворот всей лестницы в нестандартный угол не поддерживается
  и блокируется, чтобы не рисовать заведомо неверную конструкцию;
- **высота ступеней пока не подтверждена обмерами** и не является
  строительной нормой или инженерной спецификацией.

## Контроль качества
`tests/geometry-sync.mjs` сверяет ID, координаты, подъёмы и места
проёмов с исходной моделью редактора, проверяет отсутствие мутаций,
пересечения проёмов и неподдерживаемые повороты.
`tests/browser-smoke.mjs` включает синхронный режим, делает PNG,
меняет координату стены в тестовом JSON и проверяет переключение назад.
Desktop и mobile Chromium **не заменяют проверку Safari**.
